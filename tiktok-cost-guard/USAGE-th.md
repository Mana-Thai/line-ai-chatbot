# วิธีใช้ LIVE Cost Guard 🛡️ (สำหรับคนไลฟ์)

เครื่องมือช่วยเช็คว่า **ต้นทุนแอดตอนไลฟ์ กำลังกินกำไรหรือยัง** — เขียว = ยิงต่อ / เหลือง = ระวัง / แดง = สร้างแคมเปญใหม่

> ญี่ปุ่น(สำหรับผู้ติดตั้ง): 売り手に渡すタイ語クイックガイド。スクショして渡してもOK。

---

## 1. ก่อนเริ่มไลฟ์ — ตั้งค่า 1 ครั้ง (กด ⚙️ ตั้งค่า)

| ช่อง | ใส่อะไร | ตัวอย่าง |
|---|---|---|
| เป้า CPA | อยากให้ต้นทุนต่อ 1 ออเดอร์ ไม่เกินกี่บาท | 15 |
| กำไรขั้นต้น | กำไรกี่ % (0.40 = 40%) | 0.40 |
| ค่าธรรมเนียม | ค่าธรรมเนียม TikTok กี่ % | 0.05 |
| ส่วนลด | คูปอง/ส่วนลดเฉลี่ยกี่ % | 0.03 |
| ลิมิตไม่มีออเดอร์ | ยิงแอดถึงกี่บาทแต่ยังไม่มีออเดอร์ = แดง | 80 |

กด **บันทึก** แล้วปิดได้เลย (ตั้งครั้งเดียว ครั้งหน้าไม่ต้องตั้งใหม่)

## 2. ตอนเริ่มไลฟ์

1. พิมพ์ชื่อไลฟ์ (เช่น "ไลฟ์เย็น 20/7")
2. กด **▶ เริ่มไลฟ์**

## 3. ระหว่างไลฟ์ — เช็คทุก ๆ 5–10 นาที

ดูตัวเลข **ยอดสะสม** จากหน้าจอ TikTok แล้วกรอก 3 ช่อง:

- **ค่าแอด** = ค่าโฆษณาสะสม (บาท)
- **ออเดอร์** = จำนวนออเดอร์สะสม
- **ยอดขาย (GMV)** = ยอดขายสะสม (บาท)

> ⚠️ ใส่ **ยอดสะสมทั้งไลฟ์** ไม่ใช่เฉพาะรอบนี้

กด **✔ บันทึกและเช็คต้นทุน** → ดูสี

## 4. อ่านสี แล้วทำตามนี้

| สี | แปลว่า | ทำอะไร |
|---|---|---|
| 🟢 **เขียว** | ต้นทุนดี กำไรงาม | **ยิงแอดต่อได้เลย** |
| 🟡 **เหลือง** | ต้นทุนเริ่มสูง / เกินเป้า | เฝ้าดูใกล้ ๆ เตรียมสร้างแคมเปญใหม่ |
| 🔴 **แดง** | ขาดทุน / ยิงแล้วไม่มีออเดอร์ | **หยุดแคมเปญนี้ แล้วสร้างแคมเปญใหม่ทันที** |

- **CPA** = ต้นทุนต่อออเดอร์ (ยิ่งต่ำยิ่งดี)
- **คุ้มทุน** = ถ้า CPA เกินเลขนี้ = เริ่มขาดทุน
- **ROI** = ยอดขาย ÷ ค่าแอด (ยิ่งสูงยิ่งดี)

## 5. จบไลฟ์

กด **■ จบไลฟ์** (ประวัติจะถูกเก็บไว้ให้)
