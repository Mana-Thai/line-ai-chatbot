# 伝統テニス大会 オーダー表

第44回 チョンブリー県内クラブ・同好会対抗 伝統テニス大会(2026/11/14・Greta Sport Club Pattaya)の
選手名簿と、対戦ごとの5種目の組み合わせ(オーダー)を作る静的Webアプリ。サーバー不要。

- **選手名簿(管理者のみ)**: 名前・性別・年齢・出場資格・備考(生年月日など・任意)。
  10〜20人・特別枠2人までをチェック。名簿と年齢は管理者の端末にだけ保存され、共有されない。種目ごとに出場できる選手と、ペアが組めるかを表示
- **対戦オーダー**: 年齢は表示しない。選手選択欄は出場回数ごとにグループ分け(少ない順)。対戦ごとに5種目(規則3.7の試合順)のペアを選ぶ。年齢条件(各人の最低年齢・合計年齢)
  違反と、同じ対戦での1人2種目を色で警告。「空き枠を自動で埋める」は条件を満たし、
  出場数の少ない選手を優先した組み合わせを探す
- **勝率予測と提案(管理者のみ)**: 選手のレベル(1〜10)と相手の強さから、各種目の勝率
  (ペア平均レベルの差によるロジスティック曲線)と、5種目中3勝以上するチーム勝率を表示。
  「勝てる組み合わせを提案」でチーム勝率が高い順に3案を出す(`rules.js` の `suggestLineups`、分枝限定法)。
  管理者だけが見られる情報(年齢・レベル・資格・備考・勝率)は紫色の文字で表示し、共有リンクには入れない
- **出場・参加費**: 選手×対戦の出場表(出番のない選手は赤)と、参加費(既定6,000バーツ)を
  出場回数に比例して1バーツ単位で分担した金額(合計が参加費とちょうど一致)
- **メンバー用閲覧リンク**: 名前と種目、各選手の出場回数・参加費の分担だけをURL(`#view=...`)に入れた読み取り専用ページ。
  年齢・資格・備考は含まれない。オーダーを変えたらリンクを作り直して送る
- **書き出し**: 申込用名簿(規則6:男女別・若い順・特別枠明記、日本語/タイ語)と、LINE共有用オーダー文。
  データはブラウザ(localStorage)に保存。JSONファイルで保存・読み込みもできる

規則ロジックは `rules.js`(UMD)。テストは `node tennis-lineup/test.js`。
公開は `website-publish` Skill(GitHub Pages)の手順で。

## 公開構成(正式版)

| 用途 | 置き場所 | ログイン |
|---|---|---|
| 管理者版(名簿・年齢・レベル・オーダー編集) | claude.ai のページ。共有メニューで**編集者(Editor)**にした人も同じ権限 | claude.ai |
| 閲覧のみ(claude.ai) | 同じページ。共有メニューで**閲覧者(Viewer)**にした人は最新オーダーだけが自動表示 | claude.ai |
| メンバー用閲覧ページ | GitHub Pages `https://mana-thai.github.io/tennis-lineup/` | 不要 |

- 管理者版の「書き出し」→「メンバー用の閲覧リンク」は GitHub Pages のURLを指す。
  オーダーの中身(名前・種目・出場回数・参加費)はURLの `#` 以降に入り、サーバーには送られない
- 年齢・レベル・資格・備考・勝率は閲覧リンクに入らない
- 配布ファイルの作成: `python3 tennis-lineup/build.py` → `dist/admin.html`(claude.ai用)と
  `dist/viewer/index.html`(GitHub Pages用)。`pages/index.html` は Pages リポジトリに置く最新版の控え
- Pages 用リポジトリ `Mana-Thai/tennis-lineup`(公開)には `pages/index.html` を `index.html` として置く

### claude.ai 上の権限とデータ(db のルール)

- `admin/state` … 全データ(名簿・年齢・レベル等)。ルール `admin` は read/write とも admin 以上(編集者・所有者)のみ
- `public/order` … メンバーに見せる内容(名前・オーダー・出場回数・参加費)。全員が読め、書けるのは admin 以上
- 画面は `user.canEdit()` で管理者画面/閲覧画面を切り替える(表示の切替だけで、守っているのはルール)
- 編集ロック: 全体で1人だけ編集できる(`admin/lock` の lease・30秒、10秒ごとに更新)。
  後から開いた管理者には「他のユーザーが編集中です(〇〇さん)」と表示され閲覧のみになる。
  「編集を終える」・5分間操作なし・ページを閉じて30秒で解除。他の管理者の変更は自動で反映される
