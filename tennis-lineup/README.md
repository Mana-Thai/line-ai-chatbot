# 伝統テニス大会 オーダー表

第44回 チョンブリー県内クラブ・同好会対抗 伝統テニス大会(2026/11/14・Greta Sport Club Pattaya)の
選手名簿と、対戦ごとの5種目の組み合わせ(オーダー)を作る静的Webアプリ。サーバー不要。

- **選手名簿(管理者のみ)**: 名前・性別・年齢・出場資格・備考(生年月日など・任意)。
  10〜20人・特別枠2人までをチェック。名簿と年齢は管理者の端末にだけ保存され、共有されない。種目ごとに出場できる選手と、ペアが組めるかを表示
- **対戦オーダー**: 年齢は表示しない。対戦ごとに5種目(規則3.7の試合順)のペアを選ぶ。年齢条件(各人の最低年齢・合計年齢)
  違反と、同じ対戦での1人2種目を色で警告。「空き枠を自動で埋める」は条件を満たし、
  出場数の少ない選手を優先した組み合わせを探す
- **出場状況**: 選手×対戦の出場表(出番のない選手は赤)
- **メンバー用閲覧リンク**: 名前と種目だけをURL(`#view=...`)に入れた読み取り専用ページ。
  年齢・資格・備考は含まれない。オーダーを変えたらリンクを作り直して送る
- **書き出し**: 申込用名簿(規則6:男女別・若い順・特別枠明記、日本語/タイ語)と、LINE共有用オーダー文。
  データはブラウザ(localStorage)に保存。JSONファイルで保存・読み込みもできる

規則ロジックは `rules.js`(UMD)。テストは `node tennis-lineup/test.js`。
公開は `website-publish` Skill(GitHub Pages)の手順で。
