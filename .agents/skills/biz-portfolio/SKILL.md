# ポートフォリオの事例追加(納品のたびに実行)

事例の数がそのまま営業力になる。**納品して顧客が満足したタイミングで掲載許可を取り、
1件ずつ確実に追加する**。ポートフォリオサイト自体がまだ無ければ、先に `new-website`
で作成し `website-publish` で公開しておく(サンプル作品だけでもまず公開する)。

## 1. 掲載許可を取る(納品直後がベスト)

納品のお礼メッセージに続けて依頼する(日タイは相手に合わせる):

> もしよろしければ、今回の作品を制作実績としてサイトに掲載させていただけませんか?
> お名前は出しません(出したい場合は店名・リンク付きでの掲載もできます)。
> ขออนุญาตนำผลงานชิ้นนี้ไปลงเป็นตัวอย่างในเว็บไซต์ได้ไหมครับ/คะ (ไม่ลงชื่อลูกค้า)

- 返事は台帳(`business/orders.csv`)のメモに記録(「掲載OK(匿名)」「掲載NG」等)
- **許可のない作品は絶対に載せない**。返事がなければ載せない
- 店舗案件で先方が宣伝を望む場合は、店名+リンク付き掲載(相互に宣伝になる)

## 2. 匿名化のルール

| 素材 | 処理 |
|---|---|
| 人物の写真・動画 | 原則使わない。使うなら本人の明示的な許可を取り、子供は特に慎重に |
| 名前・メッセージ文言 | 見本用に差し替える(「Somchai → คุณ A」等)か、映らないシーンを選ぶ |
| ギフト動画 | 全編は載せず、個人情報のない数シーンの抜粋(10秒程度)か静止画キャプチャ |
| アパレルデザイン | デザイン画像はそのまま可(固有名入りロゴは許可の範囲を確認) |
| Webサイト/アプリ | 公開サイトはスクリーンショット+リンク。限定公開アプリはダミーデータの画面 |

## 3. 事例のフォーマット(日タイ併記)

1事例 = 画像(または動画抜粋)+短い説明。長文は書かない:

```
[画像]
チームTシャツ 胸ロゴデザイン(2色)/ โลโก้เสื้อทีม (2 สี)
制作期間: 3日 ・ 納品: 入稿用データ一式
```

- 「制作期間」「価格帯」を書くと問い合わせの質が上がる(正確な価格は書かなくてよい)
- サービス別(動画/アパレル/Web/Bot)にセクションを分け、新しい事例を上に追加
- トップページの実績数(「制作実績 ◯件」)も更新する

## 4. 更新と再公開

1. ポートフォリオのリポジトリに画像を追加(画像は横幅1200px程度に縮小して軽くする)
2. 事例ブロックを追加してHTMLを更新
3. `website-quality-check` でスマホ表示・画像サイズ・リンク切れを確認
4. `website-publish` の手順で再公開し、実際のURLで表示確認
5. 事例が3件以上たまったら、`biz-promotion` の「事例紹介」投稿の題材にする

## 注意

- 掲載後に顧客から取り下げ依頼が来たら**即日削除**する(信頼が最優先)
- 事例画像に透かしは不要だが、ダウンロードされて困る品質(原寸データ等)では載せない
