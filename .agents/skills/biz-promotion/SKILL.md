# 集客・告知コンテンツの作成(受注前)

**受注前の集客**を担当する(受注後のやりとりは `biz-customer-messages`)。
告知は「画像1枚+短い文面」が基本。LINE/Facebookでは画像が先に目に入るので、
価格とサービス名は画像の中に入れる。

## 媒体と使い分け

| 媒体 | 用途・注意 |
|---|---|
| グループLINE(既存の人脈) | 最初の告知先。**同じグループへの告知は週1回まで**(ウザがられたら終わり) |
| Facebook | タイのSME集客の主戦場。在タイ日本人グループ(日本語)とローカルグループ(タイ語)の両方に。各グループの宣伝ルールを必ず確認 |
| ポートフォリオサイト | 全告知からリンクする受け皿(`biz-portfolio` で事例を増やす) |

## 告知画像の作り方

`business/templates/quote-template.html` のスタイルを流用してHTMLで組み、PNG化する:

```bash
python artwork/tools/rasterize.py promo.html --out promo.png --width 1080 --height 1350
```

- サイズ: 正方形1080×1080 か 縦1080×1350(スマホのフィードで大きく見える)
- 入れる要素: サービス名(日タイ併記)・価格(「〜より」表記可)・作品例1点・
  連絡先(LINE ID)・締切(キャンペーン時)
- 文字は少なく大きく。スマホ実寸で読めるか必ず目視確認(タイ語の文字化けも)
- 作品例は自作サンプルか、掲載許可を得た事例のみ(`biz-portfolio` の許可ルール)

## 投稿文テンプレ(日タイ併記)

文面はテンプレを案件に合わせて書き換える。タイ語は `biz-customer-messages` の
トーン(丁寧・ครับ/ค่ะ統一)に合わせる。

**サービス告知(初回・定期)**
> 【ギフト動画つくります🎬】記念日・誕生日に、写真から30秒〜1分の動画を制作。1,500THB〜、納期◯日。
> รับทำวิดีโอของขวัญ 🎬 วันเกิด/วันครบรอบ เริ่มต้น 1,500 บาท
> 作例はこちら → <ポートフォリオURL> お気軽にLINEください!

**季節キャンペーン**
> 【母の日キャンペーン💐 8/10申込分まで】お母さんへのギフト動画 通常◯◯THB → ◯◯THB
> โปรวันแม่ 💐 สั่งภายใน 10 ส.ค.

**紹介のお願い(納品後の顧客・知人向け)**
> ご紹介で成約したら次回◯%引き(紹介された方も◯%引き)。周りに必要そうな方がいたらぜひ!

**事例紹介(実績ができたら最強の告知)**
> 先日納品した◯◯のTシャツデザイン、こんな感じに仕上がりました → 写真+一言

告知は「時期の口実」があると反応が段違い。**1ヶ月前から仕込む**。

## 告知のルール

- **価格を必ず書く**(「価格はDMで」は問い合わせが激減する)
- 連絡導線はLINE 1本に絞る(返信が分散すると事故る)
- 知人経由の告知には紹介特典を必ず添える
- 反応(問い合わせ数・成約)を投稿ごとにメモしておき、効いた媒体・文面に寄せる
- 反応が無いときは先に露出(媒体・頻度・画像)を変える。**値下げは最後の手段**
  (`business/income-plan.md` の方針)
