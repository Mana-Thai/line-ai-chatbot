# 行事別プリセット文例(make_montage_orders.py 内蔵)

`make_montage_orders.py` が CSV の `occasion` × `language` × `sender` から
montage.yaml / order.yaml に入れる下書きの一覧。**そのまま納品せず**、
ヒアリングした内容で書き替えるのが前提。

タイ語の正本(検証済み文例・キャプション集・文化の注意)は
`.claude/skills/memorial-photo-video/references/thai-templates.md`。

## 日本語

| occasion | 冒頭カード | 結びカード | 締め(couple_names) |
|---|---|---|---|
| mothers-day | お母さんへ / あなたが私にしてくれたことを ひとつずつ、思い出してみました | 言葉にしなかっただけで ぜんぶ、覚えています | お母さん、ありがとう |
| birthday | お誕生日おめでとう / いままでの「ありがとう」を この動画にこめました | これからも、ずっと 元気でいてね | お誕生日おめでとう |
| kanreki | 60年分の「ありがとう」を つたえたくて | これからは、じぶんの時間を たのしんでください | 還暦おめでとう |

| christmas | メリークリスマス / ことしも いっしょに 過ごせますように | たいせつな思い出を ありがとう | メリークリスマス |

## タイ語(sender で หนู/ผม と文末が切り替わる)

| occasion | 冒頭カード | 締め |
|---|---|---|
| mothers-day | ถึงแม่ที่รักของหนู(ผม)… | 娘: ขอบคุณนะแม่ / 息子: ขอบคุณครับแม่ + 12 สิงหาคม(仏暦) |
| birthday | สุขสันต์วันเกิดนะแม่… | สุขสันต์วันเกิดนะแม่ |
| kanreki | หกสิบปีของแม่ คือหกสิบปีแห่งการให้… | ขอให้แม่มีความสุข |
| retirement / christmas | **穴埋め**(検証済み文例なし。必ず書いてお客様確認) | 〃 |

結びはいずれも定番の「หนู(ผม)ไม่เคยพูดออกมา แต่จำได้ทุกอย่าง」系。

### タイ語プリセットを使うときの注意

- プリセットは**母(แม่)宛て**の文。父・祖母など宛先が違う注文は
  แม่ → พ่อ(父)等に置き替え、必ずネイティブ確認(=お客様確認)を通す
- 誕生日・還暦の文も sender=son なら หนู→ผม に自動で置き替わるが、
  文全体の自然さはお客様に文字で確認してもらうこと

## 書き替えの型(テンプレ感を消す一手間)

1. プリセットの結びの前に、ヒアリングで聞いた**具体的なエピソードを1行**足す
   (例: 「お弁当の卵焼き、いまでも真似できません」)
2. 冒頭カードの宛名を、お客様が実際に呼ぶ呼び方にする(お母さん/ママ/おかん)
3. `closing_date` は行事の実日付に(タイの母の日は8月12日・仏暦=西暦+543)
