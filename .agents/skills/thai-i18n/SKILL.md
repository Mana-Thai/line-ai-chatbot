# 日本語/タイ語 二言語対応チェックリスト

このアプリはタイの業者へ発注するため、**画面は日本語・CSVは日本語版とタイ語版の2種類**を出力する。
翻訳の仕組みは1箇所だけ: `shared/constants.js` の `TH` 辞書(日本語→タイ語)を
`public/app.js` の `tr(text, lang)` が引く。**辞書に無い文言は日本語のまま出力される**
(エラーにならないので漏れに気づきにくい。これが一番の落とし穴)。

## 翻訳対象のルール

- **翻訳する**: 選択肢の値(胸ロゴ・バックプリント・カラーの「持ち込み」)、CSVヘッダー、
  済/未などの固定ステータス文言
- **翻訳しない(原文のまま)**: 名前・備考・入力者などユーザーが入力した自由文、
  サイズ(S/M/L…)、カラーのコード部分(`1.BK` 等)、日時

## 選択肢や文言を追加・変更したときの手順

1. `shared/constants.js` で選択肢を追加/変更する(`CHEST_LOGOS` / `BACK_PRINTS` / `COLORS` /
   `DESIGN_IMAGE_KEYS` など)
2. **同じファイルの `TH` 辞書に対応するタイ語訳を追加する**。改名の場合は旧キーを新キーに置き換える
   - タイ語訳の既存パターンに合わせる: 有→`มี`、無→`ไม่มี`、白→`สีขาว`、
     カラー(多色)→`หลายสี`、小→`เล็ก`、大→`ใหญ่`、例: `有(ロゴ小 白)` → `มี (โลโก้เล็ก สีขาว)`
3. 選択肢を**改名**した場合は、既存データの移行も必要 → `order-data-migration` Skillに従い
   `lib/store.js` の `CHEST_LOGO_RENAMES`(または同様のマップ)に旧→新を追加する
4. CSVに**列を追加**する場合は `public/app.js` の `downloadCsv()` で:
   - ヘッダー配列に日本語列名を追加し、`TH` 辞書にその列名の訳を追加
   - 値が固定文言(済/未など)なら必ず `tr(値, lang)` を通す

## 検証(必須)

1. 漏れチェック: CSVヘッダーと全選択肢の値が `TH` 辞書に存在することを機械的に確認する。
   Nodeでの例:

   ```bash
   node -e "
   const C = require('./shared/constants');
   const headers = ['名前','胸ロゴ','バックプリント','サイズ','カラー','数量','単価','金額','支払い','受け渡し','確認者','備考','入力者','更新日時'];
   const need = [...headers, ...C.CHEST_LOGOS, ...C.BACK_PRINTS, '持ち込み', '済', '未', '合計'];
   const missing = need.filter(k => !C.TH[k]);
   console.log(missing.length ? '未翻訳: ' + missing.join(', ') : 'OK: 全て翻訳済み');
   "
   ```

   ※ ヘッダー配列は `downloadCsv()` の実装からコピーして常に最新に合わせる。
   サイズ・カラーコードは翻訳不要なので除外してよい。

2. 実CSVの確認: `order-app-regression` Skillの手順でアプリを起動し、日本語CSVとタイ語CSVを
   ダウンロードして、追加・変更した項目がタイ語版で正しく訳されていることを目視確認する

3. UIは日本語のみなので画面側の翻訳作業は不要。ただし新しい選択肢がチップ・集計表・
   受け渡しリスト・CSVのすべてに自動で現れることを確認する

## 動画・画像に焼き込むタイ語(ギフト動画/思い出アルバム動画)

Webと違い、ffmpeg の drawtext は**折り返しも字詰めもしてくれない**ため、
タイ語特有の罠がそのまま完成品に出る。ネイティブチェックで実際に指摘された点:

- **文字が小さく見える** — タイ文字は字面が em に対して小さく、声調記号・母音記号が
  上下に付く。同じptで組むと本体が潰れる。`common.THAI_SIZE_FACTOR`(1.35倍)で
  タイ語だけ自動的に大きくしている
- **単語の途中で改行される** — タイ語は単語間に空白を置かないため、機械的に折り返すと
  「เพื่อเอ / า」のように母音が基底文字から離れて壊れて見える。空白区切りの
  まとまりでのみ折り返す実装にしてあるが、**1つのまとまりが長すぎると割れる**。
  そのときは `assemble.py` が警告を出すので、**文面側に文節の空白を1つ入れて直す**
  (例: 「แม่ถักผมให้หนูก่อนไปโรงเรียน」→「แม่ถักผมให้หนู ก่อนไปโรงเรียน」)
- **字幕の書き方** — タイ語のキャプションは、はじめから文節の切れ目に半角スペースを
  入れて書く。縦型は横幅が狭く折り返しが起きやすいので特に重要
- **フォント** — Loma が自動選択される。NotoSansThai は数字・約物を持たないサブセットで
  「พ.ศ. 2569」が □ になる。完成動画は必ず再生して目視確認する
