# アパレルプリントのグラフィックデザイン

原稿は**SVG(ベクター)で作る**。拡大しても劣化せず、色の変更・修正が容易で、
Claude/Codexがコードとして直接描ける。ラスタライズは `artwork/tools/rasterize.py`
(要Chrome/Chromium/Edge。自動検出される)。

## 最初に確認すること(ユーザーへのヒアリング)

1. **モチーフと文字**: 何を描くか。入れる文字(チーム名・年号等)と言語(日/タイ/英)
2. **印刷方式**: スクリーン印刷なら**使える色数**(=版数。1〜3色が現実的)。
   DTG・転写ならフルカラー可
3. **生地の色**: 淡色(白・グレー)か濃色(黒・ネイビー)か、両方か
4. **場所とサイズ**: 胸ロゴ(目安 幅8〜10cm)/ バックプリント(目安 幅25〜30cm)

## デザイン時のルール(スクリーン印刷向け)

- **色数=版数=コスト**。指定された色数を厳守。色ごとにSVGの `fill` を分けておくと
  後で版分解しやすい(グラデーションは使わない。必要なら網点=ドットパターンで表現)
- **細線・小文字を避ける**: 線は実寸1mm以上(10cm幅のデザインなら viewBox の1%以上)。
  細かいディテールは潰れる
- **文字はパス化が安全**: SVGの `<text>` はフォント環境で見た目が変わる。
  凝った文字は図形として描くか、単純なフォントでラスタライズ後に確認する
- **濃色生地用バリエーション**: 黒生地には白ベース(色反転)版を別途作る。
  白フチ(アウトライン)を付けると濃色でも映える

## 制作フロー

1. **SVGで原稿を作成** — `artwork/works/<作品名>/design.svg`。
   viewBoxは仕上がり比率で(例: 横10cm×縦7.5cm → `viewBox="0 0 400 300"`)
2. **プレビューで確認**(生地色に重ねる):

   ```bash
   python artwork/tools/rasterize.py design.svg --out preview_white.png --width 800 --background "#FFFFFF"
   python artwork/tools/rasterize.py design.svg --out preview_black.png --width 800 --background "#1A1A1A"
   ```

   プレビュー画像をユーザーに見せて、色・バランスのOKをもらってから次へ
3. **入稿用の書き出し** — 300dpi・透過PNG:

   | 用途 | 実寸 | `--width` |
   |---|---|---|
   | 胸ロゴ | 幅8〜10cm | 945〜1200 |
   | バックプリント | 幅25〜30cm | 2950〜3600 |

   ```bash
   python artwork/tools/rasterize.py design.svg --out print.png --width 3600
   ```

4. **納品物**: `design.svg`(原稿・修正用)+ `print.png`(入稿用透過)+
   生地色プレビュー。業者にはPNGとともに「実寸幅◯cm・色数◯色」を伝える

## 関連

- ドット絵テイストのデザイン → `pixel-art` Skill
- 仕掛けのあるデザイン(逆さ絵・隠し文字等) → `gimmick-art` Skill
- 注文のとりまとめは既存のグッズ注文アプリ(管理者がサンプル画像として
  デザインPNGをアップロードすると全員の注文画面に表示される)
- (Claude Code利用時のみ)作品が増えたら `DesignSync` で claude.ai/design に
  ギャラリー同期し、ブラウザでカード一覧として眺められる
