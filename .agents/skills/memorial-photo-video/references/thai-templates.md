# タイ語文例集(思い出アルバム動画)

タイ人のお客様向けの手紙・キャプション・締めの言葉のテンプレート。
`montage.yaml` / `order.yaml` にそのまま貼れる。

## 使う前に知っておくこと

- **タイの母の日は8月12日**(シリキット王妃の誕生日)。5月の第2日曜ではない。
  父の日は12月5日(プミポン前国王誕生日)
- **母の日の花はマリ(ดอกมะลิ / 白いジャスミン)**。「母の愛の純粋さ」を表す。
  文面や写真に入れると一気にタイらしくなる
- **仏暦(พ.ศ.)**が一般的。西暦+543(2026年 = พ.ศ. 2569)。
  タイ数字(๒๕๖๙)は格式ばった印象。日常的な贈り物なら算用数字で問題ない
- **自称と文末**を依頼者の性別で変える(下表)。ここを間違えると一気に不自然になる

| 話者 | 自称 | 文末 | 「ありがとう」 |
|---|---|---|---|
| 娘(女性) | หนู(目上に対する女性の自称)/ ดิฉัน | ค่ะ / นะคะ | ขอบคุณค่ะ |
| 息子(男性) | ผม | ครับ / นะครับ | ขอบคุณครับ |

- **フォント**: `Loma` が自動選択される。**NotoSansThai は数字・約物を持たない**ため
  「พ.ศ. 2569」が □ になる。スクリプトが欠落文字を検出して警告するので、
  警告が出たら文面かフォントを見直すこと

## ① 冒頭の手紙カード

### 母の日(娘から)

```
ถึงแม่ที่รักของหนู

หนูได้นึกถึงสิ่งที่แม่ทำเพื่อหนู
ทีละอย่าง ทีละอย่าง
```
(愛するお母さんへ / お母さんがしてくれたことを ひとつずつ思い出しました)

### 母の日(息子から)

```
ถึงแม่ที่รักของผม

ผมนึกถึงทุกสิ่งที่แม่ทำเพื่อผม
ตั้งแต่วันนั้นจนถึงวันนี้
```

### 誕生日

```
สุขสันต์วันเกิดนะแม่

ขอบคุณที่อยู่ข้างๆ หนูเสมอ
ในทุกช่วงเวลาของชีวิต
```
(お誕生日おめでとう / いつもそばにいてくれてありがとう)

### 還暦・年配の母へ

```
หกสิบปีของแม่
คือหกสิบปีแห่งการให้

วันนี้ขอให้แม่ได้รับบ้าง
```
(母の60年は、与え続けた60年 / 今日は受け取ってください)

## ② 写真のキャプション(時系列)

そのまま使える定番。年号は「พ.ศ. 2539」または「ปี 2539」。

| 場面 | タイ語 | 意味 |
|---|---|---|
| 赤ちゃんを抱く母 | `พ.ศ. 2539 — วันที่แม่โอบกอดหนูครั้งแรก` | 初めて抱いてくれた日 |
| 家族写真 | `แม่อยู่ตรงกลางของครอบครัวเสมอ` | いつも家族の真ん中に |
| 学校行事 | `งานกีฬาสี วันรับปริญญา แม่มาทุกครั้ง` | 運動会も卒業式も必ず来た |
| 旅行 | `ทริปแรกของครอบครัวเรา` | はじめての家族旅行 |
| 母の笑顔 | `เสียงหัวเราะของแม่ทำให้ทั้งบ้านสว่างขึ้น` | 笑い声が家を明るくした |
| 料理 | `รสมือแม่ที่ไม่มีใครทำได้เหมือน` | 誰にも真似できない母の味 |
| 見送り | `แม่ยืนมองจนรถลับตา` | 車が見えなくなるまで見送った |
| 孫と | `และวันนี้ แม่ก็ให้ความรักแบบเดียวกันกับหลาน` | 今は孫に同じ愛を |
| 現在の母 | `วันนี้แม่ยังยิ้มเหมือนเดิม` | 今も変わらない笑顔 |

## ③ 結びの手紙カード

### 定番(娘から)

```
หนูไม่เคยพูดออกมา
แต่หนูจำได้ทุกอย่าง

ต่อจากนี้ ถึงตาหนูบ้าง
ที่จะดูแลแม่
```
(言葉にしなかっただけで、ぜんぶ覚えています / 今度は私が大切にする番です)

### 遠くに住む子から

```
ถึงจะอยู่ไกลกัน
แต่หนูคิดถึงแม่ทุกวัน

ขอบคุณที่เป็นแม่ของหนู
```
(離れていても毎日想っています / 私の母でいてくれてありがとう)

### ジャスミンに寄せて(母の日らしさを出す)

```
ดอกมะลิสีขาว
เหมือนความรักของแม่

บริสุทธิ์ และไม่เคยจางหาย
```
(白いマリの花は母の愛のよう / 純粋で、色あせない)

## お客様への確認(納品前に必ず)

タイ語は**声調記号1つで意味が変わる**ため、文面は必ず文字だけ先に送って確認してもらう
(`biz-customer-messages` Skillのテンプレートを使う)。特に:

- [ ] 自称(หนู / ผม)と文末(ค่ะ / ครับ)が依頼者の性別と合っているか
- [ ] 名前・年号(仏暦/西暦)が正しいか
- [ ] 完成動画を再生し、□ になっている文字が無いか**目視で確認**
