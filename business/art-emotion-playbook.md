# アート感情プレイブック — 感動を再現可能にする設計原則

> 目的: 「受け取った人が感動して涙を流し、心からありがとうと感じる」を
> 一回の偶然ではなく**全作品で再現できる型**にする。
> 正本の位置づけ: 作品ごとの詳細は各 `art-direction.md`(例:
> `artwork/works/gift-video-samples/mothersday-v6/art-direction.md`)が正本。
> このファイルは作品を横断する**普遍原則とチェックリスト**の正本。

## 1. v3→v7で支払った授業料(なぜこの原則なのか)

| 版 | 学んだこと |
|---|---|
| v3「二つの手のあいだ」 | 美術品質が高くても、**暗室・空席・隔たり・独り**は喪失や死を連想させ「怖い」と言われる。美しさ≠感動 |
| v4「ふたりでつくる光」 | 「一緒につくる・繕う・歩く」という**共同の動作**に置き換えると、同じ物質感でも温かくなる |
| v5「母が見つめた成長」 | 感動の源泉は映像美より**視点の一貫性**(母の視点で人生を見る)と、母の仕事机と娘の仕事机のような**構図の反復** |
| v6(7章×3カット) | 章ごとにワイド→ディテール→余韻の**カメラのリズム**を作ると長尺でも飽きない。**涙は見せるより隠す**方が観客が泣く |
| v7マッチカット | 30秒で十分泣ける。**顔を映さず手と物だけ**で語ると、観客が自分の母を代入できる。コイン→封筒の**役割の反転**が最強の物語装置 |

## 2. 感情設計の原則(10か条)

1. **感情を説明しない。痕跡で見せる** — 「愛」「感謝」の言葉や涙のクローズアップではなく、
   修繕された布、弁当、給料袋、縫い目、コインで語る
2. **顔より手** — 顔を映すと「他人の物語」になる。手と物だけなら観客が自分の家族を代入する
3. **マッチカット=時間と役割の反転装置** — 同じ構図・同じ光・同じ接点で
   「与える側と受け取る側」だけを入れ替える(v7のコイン→封筒)。偶然に見せない
4. **沈黙は音楽より強い** — 感情の頂点では音を抜く(v6第4章は効果音も消して心拍だけ)。
   フォーリー(生活音)を先に設計し、音楽は隙間に置く
5. **涙は隠す** — 登場人物が泣くと観客は泣かない。「涙を隠して笑う」「乾いた頬」まで戻す
6. **怖さ連想チェック** — 暗い空洞・空席・大きな距離・独りの人物・別れの象徴は
   喪失・死を連想させる。必ず「共にいる」「続いていく」要素を残す
7. **色は低彩度+記憶色1つ** — 全体は低彩度(紙・生地・朝の光)、その中に1色だけ
   意味を持つ色(母の日ブルー等)を通す。原色・ハート・絵文字は使わない
8. **文字は最後に一行だけ** — 説明字幕は感情を殺す。タイ語の献辞一行
   (例: `ตอนนี้…ถึงตาลูกดูแลแม่บ้างนะ`)を最後に置き、それ以外は映像に語らせる
9. **具体が普遍を語る** — 「がんばったお母さん」ではなく「1990年代の田舎の台所で
   コインを渡す手」。時代・場所・物を特定するほど、誰の記憶にも刺さる
10. **受け手固有の物を1つ入れる** — 受注制作では、その家族にしかない物
    (実際の店の看板、飼い犬、母の口癖)を1箇所だけ入れる。ここがパーソナライズの核で、
    Mini→Story→Heirloomと上がるほどこの固有要素を増やす

## 3. 商品階段とアート深度の対応(=価格の理由)

価格差は「長さ」ではなく**アートの深さ**で説明する。見積・営業でもこの言葉で語る。

| 商品 | アート深度 | 具体 |
|---|---|---|
| Mini (1,290〜2,500) | 実証済みの型に写真を流し込む | 公開代表作と同じ構成・色・音の型。写真10枚、固有要素1つ |
| Story (4,900) | その家族専用の物語設計 | 専用マッチカット1組+ヒアリングから作る章構成+専用生成音楽 |
| Heirloom (12,000〜) | 完全オリジナルの保存版 | インタビュー音声・古写真修復・固有フォーリー・複数章+献辞の手書き文字 |
| Shop Story (25,000〜) | 店の創業物語を同じ文法で | 商売の「手と物」(仕込み・道具・常連の席)で語る。広告に見えない広告 |

## 4. 季節代表作エンジン(作品が営業する仕組み)

**シーズンごとに代表作を1本作り、それ自体を広告にする。** 受注が入ったら同じ型で量産する。
制作は各シーズンの**3週間前**に開始(制作1週+告知2週)。

| 時期 | 口実 | 代表作の型 |
|---|---|---|
| 8/12 母の日 | 公開中(マッチカットv7) | 実受注で検証中 |
| 10月前後 | 敬老・故人を偲ぶ(出家・徳を積む文化) | 記憶と継承。Heirloomの入口 |
| 12/5 父の日(国王誕生日) | 父へ | 母の日の型を父の「手と物」(工具・バイク・畑)で変奏 |
| 12月末〜1月 | 新年・帰省 | 一年の感謝。家族全員型(Story向き) |
| 2/14 バレンタイン | 恋人・夫婦 | anniversary型の刷新版 |
| 4/13 ソンクラーン(家族の日) | 水掛け・帰省・敬老 | タイ最大の家族イベント。年間最大の商機として1月から仕込む |

各代表作は必ず: 縦型30秒 + ポートフォリオ掲載 + 告知画像 + 日タイ投稿文 + 受注用の型
(order.yaml と生成スクリプト)までセットで完成とする。

## 5. 納品前の感情チェックリスト(全作品で実施)

- [ ] 10か条に照らして: 説明的な字幕・涙の顔・怖さ連想(暗所/空席/独り)が残っていないか
- [ ] 音: 感情の頂点に「音の隙間」があるか。接触音(コイン・紙・布)と音楽が同期しているか
- [ ] 色: 記憶色が1色に絞れているか。原色・ハートが紛れ込んでいないか
- [ ] 固有要素: この家族/店にしかない物が最低1つ入っているか(Mini以上)
- [ ] 代入可能性: 顔の映り方は「他人の物語」になっていないか
- [ ] 技術QC: `precheck → assemble → qc` ALL PASS+代表フレーム目視(既存フロー)
- [ ] 最後に自問: **音を消して見ても泣けるか。映像を消して聴いても情景が浮かぶか**

## 6. 運用ルール

- 新しい表現の実験は代表作(サンプル)で行い、**受注制作では実証済みの型だけ**を使う
- 顧客の感想は原文のまま `business/reviews/` に保存し、次の型の改善材料にする
- この文書は代表作を1本作るたびに「学んだこと」を1行追記する(肥大化したら原則に昇華)
