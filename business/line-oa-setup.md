# 公式LINE(LINE Official Account)の設定一式

`docs/`(aniostea.com)のサイトと合わせた、タイのお客様向け公式LINEの設定と文面。
文面はそのままコピーして LINE Official Account Manager に貼れる。

**送信前の約束**
- タイ語の文末は**送り手の性別で統一**する。女性 `ค่ะ / คะ` / 男性 `ครับ`。
  この文書は **`ค่ะ` 版**で書いてある。男性が運営するなら `ค่ะ→ครับ`、`คะ→ครับ` に一括置換する
- **公開前にタイ人のネイティブに一度読んでもらう**。声調記号1つで意味が変わる
- 金額・納期はサイト(`docs/index.html`)と台帳(`business/orders.csv`)と必ず一致させる。
  片方だけ直すと必ず食い違う

## 1. アカウントの基本設定

| 項目 | 設定値 | 制限 |
|---|---|---|
| アカウント名 | `aniostea อนิโอซเตีย` | 20文字以内(19文字) |
| ステータスメッセージ | `เปลี่ยนรูปเป็นวิดีโอ`(写真を動画に) | 20文字以内(20文字) |
| プロフィール画像 | 屋号ロゴ(正方形・640x640px以上) | — |
| 背景画像 | サンプル動画の1シーン(手紙カードか家族写真) | 1080x878px |
| ウェブサイト | `https://aniostea.com` | — |
| メール | `hello@aniostea.com` | — |

**ステータスメッセージの代案**(20文字に収める。文字数はタイ文字1字=1文字)
- `วิดีโอความทรงจำให้แม่`(母への思い出動画)
- `ของขวัญจากลูก ถึงแม่`(子から母への贈り物)

### 基本情報(プロフィールの説明文)

```
เปลี่ยนรูปถ่ายของครอบครัวคุณ ให้เป็นวิดีโอความทรงจำสั้นๆ พร้อมจดหมายในแบบคำพูดของคุณเองและเพลงประกอบ

รับไฟล์ MP4 ทั้งแนวนอนและแนวตั้ง เปิดดูได้ทุกเมื่อ ไม่มีวันหมดอายุ
เหมาะกับวันแม่ วันเกิด ครบรอบ 60 ปี วันเกษียณ และทุกโอกาสพิเศษ

ปกติเสร็จภายใน 3 วัน · ดูตัวอย่างก่อนโอนเงิน
```

### 認証済みアカウントの申請(無料・推奨)

未認証だと**LINEアプリ内の検索に出ない**。タイでは検索流入が大きいので、
開設後すぐ「アカウント認証をリクエスト」する(審査数営業日)。認証されると
バッジが付き、検索に表示され、有料の広告配信も使えるようになる。

## 2. あいさつメッセージ(友だち追加時)

**ここが一番読まれる。** 4吹き出しに分ける(1吹き出し500文字以内・最大5吹き出し)。
`{ชื่อ}`(友だちの表示名)を差し込むと開封率が上がる。

### 吹き出し1 — 歓迎とサービスの説明

```
สวัสดีค่ะ {ชื่อ} ขอบคุณที่เพิ่มเพื่อนกับ aniostea 🌿

เราเปลี่ยน "รูปถ่าย" ของคุณ ให้เป็นวิดีโอความทรงจำสั้นๆ พร้อมจดหมายในแบบคำพูดของคุณเอง และเพลงประกอบ

รับเป็นไฟล์ MP4 ทั้งแนวนอนและแนวตั้ง ส่งต่อใน LINE ได้เลย เปิดดูได้ทุกเมื่อ ไม่มีวันหมดอายุค่ะ
```

### 吹き出し2 — 注文の流れ(3ステップ)

```
เริ่มง่ายๆ แค่ 3 ขั้นค่ะ

1️⃣ บอกเราว่าอยากทำให้ใคร ในโอกาสอะไร และอยากได้วันไหน
2️⃣ ส่งรูป 8–12 ใบ เรียงตามช่วงเวลา พร้อมสิ่งที่อยากบอก (เขียนสั้นๆ ก็ได้ เราช่วยเรียบเรียงให้)
3️⃣ ดูตัวอย่างที่มีลายน้ำก่อน พอใจแล้วค่อยโอนเงิน

แก้ไขได้ฟรี ไม่ต้องกังวลค่ะ
```

### 吹き出し3 — 料金と納期

```
ราคา

• แบบมาตรฐาน ฿590
  รูปสูงสุด 8 ใบ · ประมาณ 40 วินาที · แก้ไขได้ 2 ครั้ง

• แบบเขียนจดหมายให้ ฿1,290 (แนะนำ)
  รูปสูงสุด 12 ใบ · ประมาณ 60 วินาที · เราสัมภาษณ์และเรียบเรียงจดหมายให้ · แก้ไขได้ 3 ครั้ง

• เพิ่ม QR การ์ด +฿290
  การ์ดพิมพ์พร้อม QR สแกนแล้ววิดีโอเล่นทันที ใส่ในช่อดอกไม้หรือกล่องของขวัญได้

ราคารวมทุกอย่างแล้ว ไม่มีค่าใช้จ่ายแอบแฝง · ชำระผ่าน PromptPay
ปกติเสร็จใน 3 วัน · ต้องการด่วนภายใน 24 ชม. แจ้งได้ค่ะ

### 吹き出し4 — 安心材料と行動喚起

```
รูปของคุณปลอดภัยค่ะ 🔒
ใช้เฉพาะทำงานของคุณ · ไม่เผยแพร่โดยไม่ได้รับอนุญาต · ลบภายใน 30 วัน · ไม่ส่งต่อให้ใคร

พิมพ์บอกได้เลยค่ะว่าอยากทำให้ใคร ในโอกาสอะไร

## 3. 応答設定

| 項目 | 設定 |
|---|---|
| 応答モード | **チャット(手動)** — 相談内容が人それぞれなので自動応答だけでは受注できない |
| あいさつメッセージ | ON |
| 応答時間 | 例:09:00〜21:00(タイ時間)。実際に返せる時間にする |
| 応答時間外 | 自動応答メッセージ ON(下記) |
| Webhook | 使わない(旧チャットボット `index.js` は休止中) |

### 応答時間外のメッセージ

```
ขอบคุณที่ทักมาค่ะ 🙏
ตอนนี้อยู่นอกเวลาทำการ (09:00–21:00 น.) แต่เราอ่านทุกข้อความและจะตอบกลับภายใน 24 ชั่วโมงค่ะ

ระหว่างนี้ดูตัวอย่างงานและราคาได้ที่ https://aniostea.com
ถ้าอยากให้เริ่มเลย ส่งรูปและบอกโอกาสที่จะใช้มาก่อนได้เลยค่ะ
```

## 5. リッチメニュー

画像は `business/templates/line-richmenu.html` から生成する。
**PNGのままだと1MB制限を超える**ので、アップロードするのはJPG版:

```bash
python3 artwork/tools/rasterize.py business/templates/line-richmenu.html \
    --out business/line-richmenu.png --width 2500 --height 1686
python3 -c "from PIL import Image; Image.open('business/line-richmenu.png').convert('RGB').save('business/line-richmenu.jpg','JPEG',quality=88,optimize=True)"
```

- サイズ **2500×1686px**(大・6分割)。1MB以下・JPG/PNG(生成済みJPGは約167KB)
- メニューバーのテキスト: `เมนู`
- 表示設定: **デフォルトで表示**

| 位置 | ラベル | アクション |
|---|---|---|
| 左上 | ดูตัวอย่างงาน(作品例) | URL `https://aniostea.com/#sample` |
| 中上 | ราคา(料金) | URL `https://aniostea.com/#price` |
| 右上 | ขั้นตอนการสั่ง(注文の流れ) | URL `https://aniostea.com/#how` |
| 左下 | โอกาสพิเศษ(行事) | URL `https://aniostea.com/#occasions` |
| 中下 | คำถามที่พบบ่อย(FAQ) | URL `https://aniostea.com/#faq` |
| 右下 | **สั่งทำเลย(注文する)** | テキスト送信 `อยากสั่งทำวิดีโอค่ะ` → キーワード `สั่ง` の自動応答が返る |

右下だけ緑(LINEカラー)で目立たせてある。**タップ=会話開始**に繋げるのが狙い。

## 6. 一斉配信(母の日商戦のスケジュール)

**タイの母の日は8月12日**。父の日は12月5日。日本の5月ではないので間違えない。
配信は**無料枠の上限**(プランによる)を確認してから。送りすぎるとブロックされる。

| 時期 | 内容 | 文面の要点 |
|---|---|---|
| 3週間前(7/22頃) | 告知 | 「今年の母の日、写真で動画を作りませんか」+ サンプル |
| 2週間前(7/29頃) | 締切の予告 | 「8/9までのご注文で母の日に間に合います」 |
| 1週間前(8/5頃) | ラストコール | 「残り枠わずか・24時間特急も可」 |
| 前日(8/11) | QRカードの案内 | 「花束に添えるQRカード、当日でも間に合います」 |

### 例:3週間前の配信文

```
อีก 3 สัปดาห์ก็วันแม่แล้วค่ะ 🌸

ปีนี้ลองเปลี่ยนรูปถ่ายของครอบครัว ให้เป็นวิดีโอความทรงจำสั้นๆ พร้อมจดหมายในแบบคำพูดของคุณเองดูไหมคะ

ส่งรูป 8–12 ใบ แล้วบอกสิ่งที่อยากบอกแม่ เราเรียบเรียงและทำให้เสร็จภายใน 3 วันค่ะ
เริ่มต้น ฿590 · ดูตัวอย่างก่อนโอนเงิน

ดูตัวอย่างงานจริง → https://aniostea.com
```

### 例:締切の予告

```
📌 สั่งภายในวันที่ 9 สิงหาคม ทันวันแม่แน่นอนค่ะ

ตอนนี้ยังรับได้อยู่ค่ะ ส่งรูปมาก่อนได้เลย แล้วค่อยคุยรายละเอียดกัน
ถ้าเลยวันที่ 9 ยังมีแบบด่วนภายใน 24 ชั่วโมงให้เลือกค่ะ

เพิ่ม QR การ์ด +฿290 ใส่ในช่อดอกไม้ได้ด้วยนะคะ 💐
```

## 7. その他の設定

- **ショップカード**: 使わない(リピート商材ではないため。行事ごとの再注文は一斉配信で拾う)
- **クーポン**: 初回割引はやらない。値引きより「入金前にプレビュー」で不安を消す設計にしてある
- **LINE VOOM**: 完成作品(**お客様の許可を得たもののみ**)を月2〜3本。サイトの
  「写真は無断で公開しない」という約束を破らないこと
- **リッチメッセージ / カードタイプメッセージ**: 料金3プランをカード型にすると
  比較しやすい。あいさつ吹き出し3の代わりに使ってもよい
- **チャットタグ**: `สอบถาม`(問い合わせ)/ `รอรูป`(写真待ち)/ `รอโอน`(入金待ち)/
  `เสร็จแล้ว`(完了)を作り、台帳(`business/orders.csv`)のステータスと対応させる
