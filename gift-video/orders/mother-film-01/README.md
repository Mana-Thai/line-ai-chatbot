# mother-film-01 — 母と娘・1分の短編

タイの母娘の半生を9シーン・60秒で描く短編。**テキスト/キャプション/ロゴは一切入れない**
(ブリーフの指定)。ギフト動画パイプラインの `assemble.py` は文字入れ・紙テクスチャ転換を
行うため使わず、この注文専用の `build.py`(クロスフェード連結+ラスト暗転)で組み立てる。

## 構成

```
mother-film-01/
├── shotlist.json   # 正本: 9シーンの内容・Veoプロンプト・尺・仮編集のカメラワーク
├── build.py        # 生成 + 組み立て
├── stills/         # 各シーンの入力静止画 (sceneN.png = 生成用 / _original = 参考画像の原寸切り出し)
├── input/          # 各シーンの動画 (sceneN.mp4 = 本編 / previz_sceneN.mp4 = 仮編集)
└── output/         # 完成動画
```

尺の設計: シーン合計64.0秒 − クロスフェード0.5秒×8 = **60.0秒**。
配分は 7/7/7/6/6/7/8/9/7 秒で、感情の山(シーン8=母が娘の顔を包む)を最長の9秒にしている。

## 仮編集(API不要・無料)

参考画像にカメラワークを付けて尺と並びだけ確認する。

```bash
python build.py --previz     # → output/mother-film-01_previz.mp4
```

参考画像は元グリッド1枚から切り出したもので1コマ約320×180しかないため、
**仮編集の画質は本編の品質を表さない**(尺・構成の確認用)。

## 本編(要 GEMINI_API_KEY・有料)

各シーンをVeoで生成してからつなぐ。9シーン分の生成費用がかかる。

```bash
export GEMINI_API_KEY=...
python build.py                  # 全シーン生成 → 組み立て
python build.py --scenes 3,7     # 特定シーンだけ作り直す
python build.py --assemble-only  # 生成済み素材をつなぐだけ
```

生成済みの `input/sceneN.mp4` は自動でスキップされるので、気に入らないシーンだけ
削除して再実行すれば作り直せる。生成の当たり外れがあるため、重要なシーン
(1・8・9)は複数回試して選ぶ想定。

### 本編の前に差し替えたいもの

参考画像は解像度が足りないため、**本番では各シーンの入力画像を720p以上で用意し直す**
必要がある。`stills/sceneN.png` を同名で置き換えれば `build.py` はそのまま動く。
人物の同一性(母・娘の顔)を9シーンで保つには、同じ人物画像から生成するのが前提。

## 未決事項
