# 人物の参照画像 (character reference)

ここに置いた画像をVeoに渡し、**シーンをまたいで同じ顔になる**ようにする。
ファイル名は `shotlist.json` の `characters` と対応させること。

| ファイル | 人物 | 使うシーン |
|---|---|---|
| `mother_young.png` | 母(娘が幼少〜独立する頃) | 1, 2, 3 |
| `mother_old.png` | 母(現在。白髪) | 6, 7, 8, 9 |
| `daughter_child.png` | 娘(6歳) | 1, 2 |
| `daughter_adult.png` | 娘(27歳) | 3, 4, 5, 7, 8, 9 |

## 良い参照画像の条件

- **顔がはっきり大きく写っている**こと。全身の引き画より顔のアップが効く
- 正面〜斜め45度。目が開いていて、髪型・肌の質感が分かるもの
- 720p以上。暗すぎる・逆光・強い影は避ける
- 1人につき1枚。**1シーンに渡せるのは最大3枚**(Veoの制約)なので、
  複数人が出るシーンでは人数分しか渡せない

母を若年期/高年期で分けているのは、作中で年齢が変わるため。分ける必要が
なければ両方を同じ画像にしてもよい(`shotlist.json` の characters を同じパスにする)。

## 未配置のときの挙動

画像が無い人物は自動でスキップされ、警告を出して生成は続行する。
揃った人物から順に効かせられるので、全員分を待たずに試せる。
ただし参照なしのシーンは顔が別人になりやすいので、最終版では全員分を揃えること。
