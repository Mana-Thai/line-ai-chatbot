# 写真から映画風・アニメ風の画像を作る

`artwork/tools/stylize.py` を使う(Python標準ライブラリのみ、追加インストール不要)。
Gemini の画像生成APIに入力写真とスタイル指示を渡し、**被写体の見た目・構図を保ったまま**
別のスタイルの画像を生成する。

## 前提(最初に確認)

- **APIキー**: 環境変数 `GEMINI_API_KEY` が必要(旧チャットボットと同じキー)。
  未設定なら https://aistudio.google.com/apikey で取得し、環境変数かリポジトリ直下の
  `.env` に設定してもらう。**本番用の render.yaml には追加しない**(ローカルツール専用)
- **料金**: 画像1枚あたり数円(約$0.04)かかる。大量生成の前に枚数を確認する
- **人物写真**: 写っている本人の了解を得てから使う(家族・グループの仲間なら口頭でOK)。
  他人の写真や有名人の写真は使わない

## 使い方

```bash
# 実写映画風(1枚から)
python3 artwork/tools/stylize.py photo.jpg --style cinematic --out out/movie.png

# アニメ風(同じ被写体を複数枚渡すと顔・特徴の再現が安定する)
python3 artwork/tools/stylize.py face1.jpg face2.jpg face3.jpg --style anime --out out/anime.png

# シーン指定・複数枚生成・横型(ギフト動画向け)
python3 artwork/tools/stylize.py pet.jpg --style 3d --aspect 16:9 --count 3 \
  --prompt "走り回って遊んでいる、夕方の公園" --out out/pet.png
```

| オプション | 意味 |
|---|---|
| `--style` | `cinematic`=実写映画風(既定) / `anime`=アニメ風 / `3d`=3DCG映画風 / `custom`=`--prompt`のみ |
| `--prompt` | 追加指示(シーン・場所・表情・雰囲気。日本語でも通じる) |
| `--aspect` | 出力比率。`16:9`=横型シーン、`9:16`=縦型(スマホ・縦動画)、未指定=入力に合わせる |
| `--count` | 生成枚数1〜4。**まず2〜3枚生成して良いものを選ぶ**のが効率的 |
| `--dry-run` | APIを呼ばずに送る内容だけ確認(プロンプトの事前チェックに使う) |

## 入力写真のコツ

- **同じ被写体を1〜4枚**。角度違い(正面+横顔など)があると似せやすい。
  別人・別の被写体を混ぜない(合成されて崩れる)
- 顔やペットは**はっきり大きく写っている写真**を選ぶ。ブレ・逆光・極端に小さい顔は
  再現が崩れる原因
- 4枚まで・合計約14MBまで。大きすぎる場合は縮小してから渡す

## 出来上がりの確認と直し方

生成したPNGは必ずReadで目視確認してから納品・利用する:

| 症状 | 対処 |
|---|---|
| 顔・特徴が似ていない | 写真を2〜3枚に増やす(角度違い)/はっきり写った写真に替える |
| スタイルが弱い(写真っぽいまま) | `--prompt` にスタイルの強調を足す(例: "完全にアニメの絵にする") |
| 構図・服が変わってしまう | `--prompt` に「服装と構図はそのまま」と明示する |
| 画像が返らない(ブロック) | 人物の写り方が原因のことがある。写真を替えるかプロンプトを穏当にする |
| 同じ指示でも毎回違う | 正常(生成のたびに変わる)。`--count 3` で選ぶ運用にする |

## 応用・他Skillとの連携

- **ギフト動画のシーン素材に**: `--aspect 16:9` で横型生成 →
  `illustration-animation` Skill(animate.py)でカメラワークを付けて
  `orders/<注文ID>/input/sceneN.mp4` へ。思い出写真を映画風シーンにする定番パターン
- **アパレルデザインの下絵に**: 生成画像はそのままでは印刷原稿にならない。
  `apparel-graphic-design` Skill の手順(色数制限・透過PNG化)で原稿に起こす
- **LINEで共有**: PNGのまま送れる。副業案件なら `biz-delivery` Skill の
  透かしプレビュー→入金→本納品の流れに乗せる
