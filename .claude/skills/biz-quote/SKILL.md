# 見積もりの作成(日タイ併記)

受注前に**内容・金額・納期・修正回数を必ず文書で提示**する(後のトラブルの大半はここを
省略したのが原因)。見積書はLINEで送りやすい**縦長PNG画像**で作る。

## 1. ヒアリング(サービス別に確認する項目)

| サービス | 確認すること |
|---|---|
| ギフト動画 | 用途(記念日/誕生日等)・尺(30秒 or 1分)・縦/横/両方・素材は誰が用意するか(写真/イラストの点数)・入れる文字・納期 |
| アパレルデザイン | モチーフ・色数(=版数)・生地色・胸ロゴ/バックプリント・入稿先(印刷業者)の指定形式・納期 |
| Webサイト/アプリ | 目的・ページ数/機能・更新は誰がするか・公開先(独自ドメイン?)・納期 |

共通: **修正回数の上限**(2回まで無料が目安)と、**支払いタイミング**
(プレビュー確認後・納品前の前払いを推奨 → `biz-delivery` Skillの透かしプレビューと連動)。

## 2. 価格の組み立て方

- 基本式: **(作業時間の見積 × 時間レート)+ 実費**(素材購入・印刷代等は実費として分離)
- 修正3回目以降・特急(納期1/2)・追加バリエーションは**追加料金を明記**する
- 通貨はお客様に合わせてJPYまたはTHBの**どちらか一方**で提示(両方書くと為替でもめる)
- 迷ったら安くしすぎない。「今回はモニター価格」のように理由を付けて下げるのは可

## 3. 見積書PNGの作成

テンプレート `business/templates/quote-template.html` の `{{...}}` を実際の値に置き換えて
`quote.html` を作り、PNG化する:

```bash
python artwork/tools/rasterize.py quote.html --out quote.png --width 1080 --height 1528
```

- 明細行は `<tr>` を増減し、長くなったら `--height` を増やす
- 生成したPNGを**必ず目視確認**(日本語・タイ語の文字化け、金額の桁)
- 必須項目: 見積日・**有効期限**(1ヶ月が目安)・納期・支払い方法・修正回数の条件

## 4. 提示後

- 見積内容を `business/orders.csv` に「見積中」で登録(`biz-order-ledger` Skill)
- 提示メッセージの文面は `biz-customer-messages` Skill(日タイのテンプレあり)
- 1週間返事がなければリマインド(同Skill)
