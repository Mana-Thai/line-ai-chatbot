# QR動画ギフト(読み取ると動画が始まる実物)

完成した動画を**QRコード付きの実物**にして渡す商品型。Etsyではぬいぐるみ+QR、
カード+QRの形で売られており、**動画単体より単価を上げられる**うえに
「手に取れる贈り物」になるのが差別化点。どの動画商品
(memorial-photo-video / gift-video / drama-video-*)にも後付けできる。

## 全体の流れ

```
完成動画 → ①URL化 → ②QR生成(qr_gift.py) → ③カード制作(テンプレ→PNG)
  → ④実機で読み取り検証 → ⑤印刷 → ⑥実物に貼る/挟む → 納品
```

## ① 動画をURLにする(最重要の判断)

**QRに入れたURLは印刷後に変えられない。**「消えない・変わらない」置き場を選ぶ:

| 置き場 | 向き・不向き |
|---|---|
| **YouTube 限定公開**(推奨) | 無期限・高画質・スマホで確実に再生。URLを知る人だけ見られる。検索には出ない |
| Google Drive 共有リンク | 簡単だがアカウント容量に依存。整理中に消しやすいので専用フォルダに隔離する |
| 短縮URL(lin.ee等) | **使わない**。サービス終了・有効期限でQRが死ぬ |

- YouTube は「子供向けか」の設定と、BGMの著作権チェック(Content ID)に注意。
  購入音源のライセンスが「配信可」かを確認してから上げる
- アップ後、**シークレットウィンドウで開いて**ログインなしで再生できるか確認

## ② QRコードを作る

```bash
pip install segno   # 初回のみ(純Python・依存なし)
python3 artwork/tools/qr_gift.py "https://youtu.be/XXXX" --out work/qr.png
python3 artwork/tools/qr_gift.py "https://youtu.be/XXXX" --out work/qr.svg  # 印刷所入稿はSVG
```

- 誤り訂正H(30%復元)で生成される。**QR本体は装飾しない**。飾りは周囲に
  (`gimmick-art` のQRアートの原則。中央への小ロゴはHなら可)
- 印刷の一辺は**2cm以上**。スクリプトが300dpi換算のサイズを表示する
- QRの色(--dark)を変える場合は濃色のみ。淡色・背景との低コントラストは読めない

## ③ カードにする

テンプレート `business/templates/qr-card-template.html`(A6縦・
思い出アルバム動画の手紙カードと同じ水彩調=動画と実物の世界観が揃う):

```bash
mkdir -p work && cp business/templates/qr-card-template.html work/card.html
cp work/qr.png work/qr.png   # qr.png はHTMLと同じフォルダに置く
# card.html の「▼▼ 編集する場所 ▼▼」(宛名・ひとこと・案内・差出人)を書き替え
python3 artwork/tools/rasterize.py work/card.html --out work/card.png --width 1240 --height 1748
```

- 1240x1748px = A6・300dpi。ハガキ(100x148mm)なら --width 1181
- 日タイ併記のままで両国のお客様に使える。タイ語だけにする場合も
  「สแกนด้วยกล้อง(カメラで読み取って)」の案内行は必ず残す
- 花束タグ・写真立て台紙など別の形は、このテンプレの寸法とQR部分を流用して作る

## ④ 検証(印刷前に必ず)

- [ ] **card.png をスマホの実機で読み取る**(カメラアプリとLINEのQRリーダー両方)
- [ ] 読み取り先がログインなし・シークレットウィンドウで再生できる
- [ ] 画面表示だけでなく、**試し印刷を1枚**して紙からも読み取る
      (画面で読めても印刷のかすれ・サイズ縮小で読めないことがある)

## ⑤ 印刷と実物

- 自宅プリンタ: 光沢紙かマット厚紙。インクジェットの普通紙はにじんでQRが死にやすい
- 印刷所・コンビニ: PNGなら300dpi厳守、できればSVG→入稿形式に変換
- 実物の例と原価感: カード(紙代のみ)/ 写真立て+台紙 / 花束のタグ(穴+リボン)/
  ぬいぐるみ+タグ。**実物の原価+制作費**で見積もる(`biz-quote`)

## 納品・運用の約束

- 納品時に「動画は消さずに保管します」と伝える(URLが生きている限りQRは有効)。
  **アップ先の動画を消したり限定公開を解除したりしない**こと。案件IDとURLの対応を
  `business/orders.csv` の備考に残す
- お客様都合でURL変更が必要になったら、QR・カード・実物も作り直しになると先に説明する
- 透かしプレビュー→入金→本納品の流れは `biz-delivery`。QRギフトの場合、
  **入金前はQRを渡さない**(プレビューは動画の透かし版のみ)
