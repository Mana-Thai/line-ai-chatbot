# 店舗向けLINE AI応答Bot(導入+月額運用)

顧客(飲食店・小売店等)のLINE公式アカウントに、営業時間・メニュー・場所などの
FAQへ自動応答するAI Botを導入し、**導入費(10,000〜25,000 THB)+月額運用費
(1,500〜3,000 THB)**で提供する。月額が積み上がる継続収入の柱なので、
納品して終わりにせず運用まで請け負う前提で設計する。

## 商品構成

| 項目 | 内容 |
|---|---|
| 導入費 | ヒアリング・FAQ整備・Bot構築・デプロイ・テスト・使い方説明 |
| 月額運用費 | FAQ更新(月2回まで)・応答品質チェック・API利用料込み・障害対応 |
| 追加料金 | FAQ大幅追加、多店舗展開、予約/注文機能(→ `new-shared-webapp` で別見積) |

月額にAPI利用料を含めるため、原価(API費)を必ず見積もる(下記)。

## 構築手順

### 1. ヒアリング(見積もり前に必ず)

- FAQの元ネタ: 営業時間・場所・メニュー/価格・支払い方法・よくある質問(10〜30問が目安)
- 応答言語: タイ語のみ / 日タイ / +英語
- **答えてはいけないこと**(価格交渉・クレーム対応等)と、人に引き継ぐ条件
- 月間の想定メッセージ数(月額のAPI原価計算に使う)
- 見積もりは `biz-quote`、受注したら `biz-order-ledger` に記録

### 2. LINE公式アカウントの準備

- **顧客のLINEビジネスIDでアカウントを作る**(自分のアカウントで作らない —
  `biz-delivery` の引き継ぎルールと同じ)。作業用に管理者権限をもらう
- LINE Developers でMessaging APIチャネルを作成し、
  `LINE_CHANNEL_ACCESS_TOKEN` / `LINE_CHANNEL_SECRET` を取得
- 応答設定: あいさつメッセージON、応答メッセージOFF、Webhook ON

### 3. Botの実装(index.js を雛形に顧客別に作る)

リポジトリの `index.js`(旧チャットボット)が雛形。顧客ごとに別リポジトリ
(またはフォルダ)へコピーして以下を改修する:

- **Gemini → Claude API に載せ替え**(`@anthropic-ai/sdk`)。モデルは品質重視なら
  `claude-opus-4-8`、応答量が多くAPI原価を抑えたい案件は `claude-haiku-4-5` を
  顧客ごとに選ぶ(下の料金表で原価を試算して決める)
- システムプロンプトに店舗情報+FAQ全文を埋め込む(FAQは `faq.md` 等の別ファイルに
  分離し、更新しやすくする)。**「FAQに無いことは推測で答えず、人への引き継ぎ文言を返す」**
  を必ず入れる(営業時間や価格の誤答は店の信用問題になる)
- 応答言語の指示(タイ語で聞かれたらタイ語で答える等)と、店のキャラクターに合う口調
- 会話履歴は `index.js` と同じインメモリ方式で十分(FAQ応答に長期記憶は不要)
- `/healthz` はそのまま残す(Renderのヘルスチェック)

### 4. デプロイと動作確認

- 顧客ごとにRenderの新サービスとしてデプロイ(手順は `app-publish` に準ずる。
  Webhook URL: `https://<サービス名>.onrender.com/webhook` をLINE Developersに設定)
- 環境変数: `LINE_CHANNEL_ACCESS_TOKEN` / `LINE_CHANNEL_SECRET` / `ANTHROPIC_API_KEY`。
  **キー類はリポジトリに絶対に入れない**
- テスト: FAQ全項目を実際にLINEから質問(タイ語・日本語両方)。FAQ外の質問で
  引き継ぎ文言が返ることも確認。おかしな応答はプロンプトを直して再テスト
- Render無料プランはスリープで初回応答が遅い。顧客に事前説明するか有料プランを提案

### 5. 納品

- 透かしはないので、動作確認をもって「確認待ち」→入金→本番引き渡し(`biz-delivery` の
  入金フローに従う)。使い方(FAQ更新の依頼方法・引き継ぎ条件)を説明して「完了」

## API原価の見積もり(月額の値付けに必須)

1回の応答 ≒ 入力2,000トークン(プロンプト+FAQ+履歴)+出力300トークン程度。
料金(1Mトークンあたり、2026-06時点): Opus 4.8 = 入力$5/出力$25、
Haiku 4.5 = 入力$1/出力$5。

- 例: 月3,000メッセージ × Haiku 4.5 ≒ $10前後/月 → 月額1,500THBでも十分な粗利
- 例: 同条件 × Opus 4.8 ≒ $50前後/月 → 月額2,500THB以上に設定する
- プロンプトキャッシュ(FAQ部分に `cache_control`)で入力コストは大きく下がる
- 最新の料金・実装は `claude-api` Skillで必ず確認してから見積もる

## 月次運用(月額費の中身)

1. 応答ログの品質確認(誤答・引き継ぎ漏れがないか)
2. 顧客からのFAQ更新依頼を反映(月2回まで。超過は追加料金)
3. API利用額の確認(想定超過が続くなら月額改定を相談)
4. 対応内容を `business/orders.csv` のメモに記録(`biz-order-ledger`)

## 注意

- 解約時の扱い(Botの停止・アカウント返却)を契約時に決めておく
- 同業他店へ同じFAQ構成を使い回すのは可、**顧客固有の情報は絶対に流用しない**
- デモBot(自分用の見本)を1本常設しておくと営業が楽(`biz-promotion` の営業資材)
