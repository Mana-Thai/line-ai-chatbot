# 素材の事前チェックと対処(ギフト動画)

エンコードは1件あたり数分かかるので、失敗は**組み立て前に**素材段階で潰す。
`gift-video/` を基準に実行:

```bash
python scripts/precheck.py <注文ID>      # 1注文
python scripts/precheck.py --all         # 全注文(量産時)
```

FAILが1件でもあれば exit 1(WARNのみなら通る)。チェック項目と対処:

## FAIL(直すまで組み立てない)

| 項目 | 意味と対処 |
|---|---|
| order.yaml | 必須項目(`order_id` / `couple_names` / `anniversary_date`)の欠落、`target_duration` が10〜300秒外など。order.yaml を修正 |
| シーン素材なし | `input/scene1.mp4` から番号順に配置する |
| 映像ストリームなし/読めない | 素材が壊れているか音声のみ。AI生成をやり直すか再エンコードする |
| シーンが短すぎ(2秒未満) | クロスフェード(0.5秒×前後)が成立しない。素材を2秒以上にする |
| 総再生時間(計算値) | シーン合計が `target_duration` −2〜+5秒に入っていない。メッセージに「あと約N秒分」と出るので、シーンを追加/削除・尺調整するか、意図した尺なら `target_duration` を変更 |
| message_start_sec | 総再生時間の範囲外。開始秒を `総尺−1` 未満にする(1分動画で30秒注文の初期値22のままになっていないかも確認) |
| BGMなし/読めない | `input/bgm.mp3`(拡張子・ファイル名はこの通り)を配置する |

## WARN(組み立て可能だが品質に影響)

| 項目 | 意味と対処 |
|---|---|
| 連番の抜け(scene1,3など) | 置き忘れの可能性。意図的でなければ欠番の素材を配置(欠番のままでも連結はされる) |
| 解像度不足(1920x1080未満) | 拡大されて画質が落ちる。可能ならフルHD以上で素材を作り直す(縦型メインなら縦長素材でもよい) |
| BGMが総尺より短い | 不足分が無音で埋まる。曲を差し替えるか、尺をカバーする長さにする |

## 素材を作る側への指定(AI生成時のガイド)

量産時は素材の作り方を最初に揃えるのが最も効率的:

- **シーン**: mp4(H.264推奨)、フルHD(1920x1080)以上、1本あたり `target_duration÷シーン数` 秒
  (1分×6シーンなら各10秒)。音声トラックは不要(使われない)
- **BGM**: mp3、総尺+2〜3秒以上。音量はバラバラでよい(-14 LUFSに自動正規化される)
- **ファイル名**: `scene1.mp4, scene2.mp4, ...` と `bgm.mp3` の固定名

## precheckが通ったのにQCで落ちるとき

- ラウドネス: BGMがほぼ無音だと正規化しきれないことがある。実音源に差し替える
- 想定値との不一致(±0.5秒超): 素材の再配置後に `assemble.py` を再実行していない。
  組み立てからやり直す
