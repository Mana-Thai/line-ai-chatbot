# ギミックアート(仕掛けのあるデザイン)

「気づいた人だけ分かる」仕掛けはアパレルやプレゼントと相性が良い。
**仕掛けは必ず機械的に検証する**(作った本人は分かった気になりやすい)のが鉄則。

## 仕掛けのパターン集(どれを作るか最初に決める)

| パターン | 内容 | 作り方の要点 |
|---|---|---|
| **逆さ絵** | 180°回転すると別の絵/文字に見える | 上下それぞれの見え方をラフに決め、共通の輪郭を探す。数字・アルファベットは相性表がある(例: 6⇔9、M⇔W、b⇔q) |
| **隠し文字(ネガティブスペース)** | 図形のすき間が文字になっている | 先に文字を配置し、その周囲を図形で埋める順で作る(逆は破綻しやすい) |
| **アンビグラム** | 回転/反転しても同じ語、または別の語に読める | 1文字ずつ「上下から読める字形」を設計。短い単語(2〜6文字)に限定する |
| **QRコードアート** | 実際に読めるQRをデザインに溶け込ませる | QR本体は改変せず、余白・周囲を装飾する。QRの誤り訂正レベルH(30%)なら中央に小さくロゴを重ねられる |
| **視覚トリック** | 不可能図形・錯視(同じ長さが違って見える等) | 既知の錯視(ペンローズの三角形、ミュラー・リヤー等)をモチーフに再構成する |
| **切替わり** | 見る距離で別の絵(モザイク文字)、畳むと完成する絵(アパレルの袖・裾) | 近距離=ディテール / 遠距離=シルエットの2層で設計 |

## 制作フロー

1. 仕掛けのパターンと「気づいたときに何が見えるか」をユーザーと合意する
2. SVGで作成(`apparel-graphic-design` と同じ流儀。`artwork/works/<作品名>/`)
3. **仕掛けの検証(必須)** — 目視に頼らず機械的に:

   ```bash
   # 通常向きと180°回転を並べて書き出し、両方の見え方を確認する
   python artwork/tools/rasterize.py design.svg --out normal.png --width 800
   ffmpeg -y -i normal.png -vf "rotate=PI" rotated.png
   ```

   - 逆さ絵・アンビグラム: `rotated.png` をユーザーに見せて「回転後も意図どおり読めるか」確認
   - 隠し文字: 縮小版(`--width 200`)でも文字が浮かぶか確認
   - QRコード: 書き出したPNGを**実際にスマホで読み取ってもらう**。
     装飾を足すたびに再確認(読めなくなる一番の原因は装飾の重ねすぎ)
4. アパレルに載せる場合は `apparel-graphic-design` の印刷制約・入稿フローに合流する

## 注意

- 仕掛けを詰め込みすぎない。**1作品に仕掛けは1つ**が原則
- 逆さ絵・アンビグラムは日本語(漢字・かな)では難度が非常に高い。
  まず英字・数字・記号で設計し、日本語は「隠し文字」方式が現実的
- QRの中身(URL)は変わらないか公開してよいものにする(短縮URLは有効期限に注意)
