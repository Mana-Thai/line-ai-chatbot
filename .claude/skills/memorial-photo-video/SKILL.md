# 思い出アルバム動画(写真から作る贈り物動画)

欧米で定番の「あなたが私にしてくれたこと」型。**お客様の実際の写真**を時系列に並べ、
カメラワーク・キャプション・BGMを付けて1本にする。

**AI動画生成は使わない。** 生成コストがゼロなので低価格帯でも利益が出る
(AI生成だと1本$6〜30かかり、この価格帯では成立しない)。

## 標準構成(母親向け・そのまま使える型)

時間順に並べるのが要。**成長する子ども側ではなく、母親の変化**が見えるように選ぶ:

| # | 内容 | キャプション例 |
|---|---|---|
| 1 | 赤ちゃんの自分を抱く母 | 「1996年 — わたしを抱いてくれた日」 |
| 2 | 幼少期の家族写真 | 「いつも、家族の真ん中にいた」 |
| 3 | 学校行事(運動会・卒業式) | 「運動会も卒業式も、必ず来てくれた」 |
| 4 | 家族旅行 | 「はじめての家族旅行」 |
| 5 | 母が笑っている写真 | 「その笑い声が、家じゅうを明るくした」 |
| 6 | 孫と一緒の写真 | 「そして今、孫たちに同じ愛を」 |
| — | 締め | **「お母さん、ありがとう」**(`couple_names` に入れる) |

誕生日・還暦・クリスマスも同じ型で、締めの言葉と年号を変えるだけで流用できる。

## 作り方

```bash
cd gift-video

# (1) 注文フォルダを作り、写真を photos/ に時系列順の名前で入れる
python3 scripts/new_order.py mom-001
mkdir orders/mom-001/photos      # 01-baby.jpg, 02-family.jpg ... と並ぶ名前にする

# (2) 写真リストの雛形を作り、キャプションを書き込む
python3 scripts/build_montage.py mom-001 --init
#     → orders/mom-001/montage.yaml の caption を埋める

# (3) 写真を動画化(カメラワークが自動で付く)
python3 scripts/build_montage.py mom-001
#     → 最後に order.yaml へ貼る target_duration と scene_captions が表示される

# (4) order.yaml を更新し、BGMを input/bgm.mp3 に置く

# (5) 組み立て → 品質チェック
python3 scripts/assemble.py mom-001 && python3 scripts/qc.py mom-001
```

実例: `gift-video/orders/mothers-day-demo/`(6枚・32秒・横型と縦型の両方)

## 押さえるべき点

- **写真の解像度**: 出力の1.5倍以上(1920x1080なら3000px幅以上)。ズームで使うため、
  小さい写真はぼやける。スクリプトが幅を見て警告する。古い紙焼き写真はスマホで
  撮るのではなく、明るい場所で真上から撮ってもらう
- **尺**: 1枚4〜6秒。**写真8〜15枚で40〜80秒**が目安。長すぎると最後まで見てもらえない
- **縦型も一緒に出す**: `output_formats: ["landscape", "portrait"]`。SNS・LINEで送るなら
  縦型が主役になる
- **締めの言葉**は `couple_names` に入れる(ラスト2秒に大きく出る)。
  `anniversary_date` は「2026 母の日」のように使う
- **キャプションは短く**。画面下に1〜2行。年号を入れると時間の流れが伝わる
- **BGM選び**が仕上がりの半分を決める。静かなピアノが外さない。著作権に注意
  (フリー音源か購入したものを使う)

## 二段階の商品設計

欧米では写真だけの簡易版が数ドル、制作代行が高価格帯で売られている。同じ形にできる:

| プラン | 内容 | 手間 |
|---|---|---|
| 簡易版 | お客様が写真を送るだけ。キャプションは年号や定型文 | 30分程度 |
| 制作代行 | ヒアリングして写真を選び、キャプションを書き、BGMを選ぶ | 2〜3時間 |

見積もりは `biz-quote`、受注記録は `biz-order-ledger`、納品は `biz-delivery`
(透かしプレビュー → 入金 → 本納品)を使う。**生成コストがゼロなので、価格は
ほぼそのまま利益**になる点が他のAI動画サービスとの違い。

## 品質チェック

- [ ] 写真が時系列に並んでいる(順番の入れ替わりは一番目立つミス)
- [ ] キャプションの誤字・年号の間違いがない(**お客様に文字だけ先に確認してもらう**)
- [ ] 顔が切れていない(ズーム・パンで見切れないか実際に再生して確認)
- [ ] qc.py ALL PASS(横型・縦型の両方)
- [ ] business/orders.csv に記録した
