# 思い出アルバム動画(写真+手紙で作る贈り物動画)

欧米(Etsy/Fiverr)で定番の商品型。完成品納品型は約$150、テンプレ簡易版は数ドルで
売られている。**お客様の実際の写真**と**手紙(文章)**で作り、AI動画生成は使わない。
生成コストがゼロなので、価格がほぼそのまま利益になる。

## 商品の3部構成(人気商品に共通する型)

**映像で驚かせるのではなく、手紙が商品価値の中心。** 写真は手紙の証拠として並ぶ。

| 部 | 内容 | 実装 |
|---|---|---|
| ① 冒頭 | 手紙カード「お母さんへ…」(宛名と書き出し) | `montage.yaml` の `letter:` |
| ② 本編 | 時系列の写真(**最大12枚目安**)+1行キャプション | `file:` + `caption:` |
| ③ 結び | 手紙カード(いちばん伝えたい言葉)→ 締めタイトル | `letter:` + order.yaml の `couple_names` |

- 手紙カードは水彩調の淡い背景(クリーム→ローズ)に焦げ茶の文字で全画面表示される。
  改行はそのまま反映されるので、**詩のように短い行で書く**と美しい
- 演出は上品さ優先。ゆっくりしたズーム/揺れのみで、派手なパンは使わない
  (参考商品は「花・柔らかい色・落ち着き」が共通項)

## 用途別の言葉(母の日限定にしない)

販売期間を延ばすため、同じ型を言葉の差し替えで全行事に対応させる:

| 行事 | 冒頭カード | 締め(couple_names / anniversary_date) |
|---|---|---|
| 母の日 | お母さんへ | お母さん、ありがとう / 2026 母の日 |
| 誕生日 | お誕生日おめでとう | これからも、元気でいてね / 60th Birthday |
| 還暦 | 60年分の「ありがとう」 | 還暦おめでとう / 2026.5.10 |
| 退職 | 長い間、おつかれさまでした | 第二の人生を、楽しんでね |
| クリスマス | メリークリスマス | 今年も一緒に過ごせますように |

## 作り方

```bash
cd gift-video

# (1) 注文フォルダを作り、写真を photos/ に時系列順の名前で入れる
python3 scripts/new_order.py mom-001
mkdir orders/mom-001/photos      # 01-baby.jpg, 02-family.jpg ... と並ぶ名前にする

# (2) 構成の雛形(手紙カード2枚+写真)を作り、手紙とキャプションを書き込む
python3 scripts/build_montage.py mom-001 --init
#     → orders/mom-001/montage.yaml を編集

# (3) 写真+手紙カードを動画化(カメラワークが自動で付く)
python3 scripts/build_montage.py mom-001
#     → 最後に order.yaml へ貼る target_duration と scene_captions が表示される

# (4) order.yaml を更新し、BGMを input/bgm.mp3 に置く

# (5) 組み立て → 品質チェック
python3 scripts/assemble.py mom-001 && python3 scripts/qc.py mom-001
```

**縦型(スマホ用)も納品する場合は2パス方式**(横型素材のクロップでは手紙が切れる):
横型パス(`output_formats: ["landscape"]`)の後、`build_montage.py mom-001 --size 1080x1920`
でシーンを作り直し、`output_formats: ["portrait"]` にして assemble → qc をもう一度。

実例: `gift-video/orders/mothers-day-demo/`(手紙2枚+写真6枚・46秒・両画角)

## 押さえるべき点

- **写真は8〜12枚に絞る**(参考商品の上限も12枚)。多いほど良いのではなく、
  1枚1枚に意味がある方が刺さる。尺は40〜80秒が目安
- **写真の解像度**: 出力の1.5倍以上(1920x1080なら3000px幅以上)。スクリプトが警告する。
  古い紙焼き写真は明るい場所で真上から撮ってもらう
- **手紙は依頼者の言葉で**。定型文で済ませず、ヒアリングで具体的なエピソードを
  1つ引き出して結びに入れると、既製テンプレとの差になる
- **BGM選び**が仕上がりの半分。静かなピアノが外さない。著作権に注意(フリー音源か購入)
- **「いつでも繰り返し見られる」を訴求**する(離れて暮らす家族向けに刺さる)
- 納期を売りにするなら「24時間納品」(参考商品の訴求。実作業は1〜2時間)

## 商品展開(参考商品の価格帯に合わせる)

| プラン | 内容 | 参考価格帯 |
|---|---|---|
| 簡易版 | 写真を送るだけ。手紙・キャプションは定型文 | 数百円〜 |
| 制作代行 | ヒアリング→写真選定→手紙の代筆→BGM選定 | 数千円(海外は$150前後) |
| **QRギフトセット** | 動画+**QRコード付きの実物**(カード・写真立て・花束タグ・ぬいぐるみ) | 実物の原価+制作費 |

QRギフトの作り方: 動画をYouTube(限定公開)かGoogle Driveに上げ、そのURLをQRコード化して
カード等に印刷する。「読み取ると動画が始まる」体験が差別化になり、実物とセットで
単価を上げられる。デザインは `apparel-graphic-design` / `gimmick-art` Skillが流用できる。

見積もりは `biz-quote`、受注記録は `biz-order-ledger`、納品は `biz-delivery`
(透かしプレビュー → 入金 → 本納品)。

## 品質チェック

- [ ] 写真が時系列に並んでいる(順番の入れ替わりは一番目立つミス)
- [ ] **手紙・キャプションの文面をお客様に文字だけ先に確認してもらった**(誤字・年号)
- [ ] 手紙カードの行の折り返しが不自然でない(気になる場合はYAMLで改行位置を手で指定)
- [ ] 顔が切れていない(ズームで見切れないか実際に再生して確認)
- [ ] qc.py ALL PASS(納品する画角すべて)
- [ ] QRギフトの場合: 印刷前に実機でQRを読み取って再生確認
- [ ] business/orders.csv に記録した
