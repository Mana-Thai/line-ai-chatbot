# ローカルPCエージェント (Windows)

自分のWindows PCの中で動かすAIエージェント。**PC内のファイル・フォルダをそのまま扱える**のが目的で、
必要なら画面のクリック操作もできる。

Claude API を呼び、返ってきた指示を `agent.py` が**このPC上で実行**する。
外から接続を受ける口は開かない(通信は `api.anthropic.com` への外向きHTTPSのみ)。

```
あなた> 先月のLINEでもらった見積り依頼、Documentsのどこかにあるはず。まとめて一覧にして

  → search_files    (Documents 以下を検索)
  → str_replace_based_edit_tool  (見つかったファイルを読む)
  → shell           (CSVに書き出す)
```

## できること

| ツール | 用途 |
|---|---|
| `search_files` | ファイル名(glob)・中身(正規表現)で検索。どこにあるか分からないファイルを探す |
| `str_replace_based_edit_tool` | ファイルの閲覧・新規作成・部分置換・行挿入 |
| `shell` | PowerShell コマンドの実行。コピー・移動・圧縮・アプリ起動・一括処理 |
| `computer` | 画面キャプチャ + マウス/キーボード操作(`--gui` のときだけ) |

文字コードは UTF-8 / cp932 / UTF-16 を自動判別するので、日本語Windowsのテキストもそのまま読める。

## セットアップ

必要なもの: **Python 3.10 以上**(`python.org` からインストール。「Add Python to PATH」にチェック)。

1. このフォルダをPCにコピーする(リポジトリごと `git clone` でもよい)
2. APIキーを環境変数に設定する — PowerShell で:

   ```powershell
   setx ANTHROPIC_API_KEY "sk-ant-..."
   ```
   設定したらPowerShellを一度閉じて開き直す。キーは https://console.anthropic.com で発行する。

3. 起動する:

   ```powershell
   .\run.bat
   ```

   初回だけ `.venv` を作って依存パッケージを入れる(1〜2分)。2回目以降はすぐ立ち上がる。

## 使い方

```powershell
.\run.bat                                   # 対話モード(既定: ホームフォルダのみ許可)
.\run.bat --task "デスクトップのスクショを日付フォルダに仕分けして"
.\run.bat --root D:\work --root C:\Users\me\Documents   # 許可フォルダを指定
.\run.bat --read-only                       # 閲覧と検索だけ(安全に試したいとき)
.\run.bat --gui                             # 画面のクリック・キー入力も許可
.\run.bat --auto-approve                    # 確認プロンプトなし(自己責任)
```

対話モードは `exit` で終了。処理の途中で止めたいときは `Ctrl+C`。

| オプション | 既定 | 説明 |
|---|---|---|
| `--root` | ホームフォルダ | 読み書きを許可するフォルダ。複数指定可 |
| `--gui` | 無効 | 画面操作を有効化。`pip install pyautogui pillow` が必要 |
| `--read-only` | 無効 | 閲覧・検索のみ。書き込みとコマンド実行を全部拒否 |
| `--auto-approve` | 無効 | 確認プロンプトを出さない |
| `--model` | `claude-opus-5` | 使うモデル |
| `--effort` | `high` | 思考の深さ (`low`〜`max`)。軽い作業は `low` で速く安くなる |
| `--max-steps` | 40 | 1指示あたりのツール実行回数の上限 |

## 安全のしくみ

実データを扱うので、既定はかなり慎重に倒してある。

- **フォルダ制限** — `--root` の外は読み書きしない。`..` やシンボリックリンクで抜けようとしても
  絶対パスに解決してから判定するので通らない。
- **都度確認** — ファイルの作成/上書き/置換、シェル実行、画面操作の前に `[y/N]` を聞く。
  内容(対象パス・コマンド)を表示してから聞くので、意図しない操作はその場で止められる。
- **上書きは自動退避** — 既存ファイルを上書きするときは `ファイル名.bak` を残す。
- **`--read-only`** — 書き込み系を全部拒否。まず何ができるか見たいときはこれで。
- **フェイルセーフ** — `--gui` 中にマウスが暴走したら、マウスを**画面の左上隅**に振り切ると中断する。

慣れるまでは `--read-only` → 都度確認 → `--auto-approve` の順に緩めるのがおすすめ。

## 画面操作 (`--gui`) について

ファイルやコマンドで済むことは、画面クリックでやらせないほうが速くて確実。
`--gui` が要るのは「GUIしか操作手段がないアプリ」を触るときだけ。

- 送るスクリーンショットは自動で 1920x1080 以下に縮小し、座標は実画面に戻して操作する
- 履歴に残すスクショは直近3枚だけ(コンテキストとコストの節約)
- 日本語の入力はキーストロークでは打てないので、クリップボード経由で貼り付ける
- 画面操作のツールは `claude-sonnet-5` で動作が確認されているバージョン (`computer_20251124`) を使う。
  `--gui` でツールバージョンのAPIエラーが出たら `--model claude-sonnet-5` を試す

## 費用の目安

トークン課金。ファイル検索や編集が中心なら1タスク数円〜数十円程度だが、
**スクリーンショットは1枚で数千トークン**使うので `--gui` は跳ね上がりやすい。
軽い作業は `--effort low` にすると安くなる。

## 制限

- Windows前提(`shell` は PowerShell を呼ぶ)。macOS/Linux では bash にフォールバックする
- 対話入力を求めるコマンド(パスワード入力など)は実行できない — 応答できずタイムアウトする
- `search_files` の中身検索はテキスト系の拡張子のみ。Excel/PDF の中身は `shell` 経由で処理する
- 1つのツール結果は3万文字で打ち切る(大きすぎる出力は分割して読ませる)

## 仕組み

computer use もファイル編集も**クライアント実行型のツール**で、APIは「何をするか」を返すだけ。
実際にファイルを開き、コマンドを走らせ、マウスを動かすのは `agent.py`。
だから「このPCで動かす＝このPCが操作対象になる」という関係になっている。

```
あなたのPC                              Anthropic API
  agent.py ──── 指示 + 画面/ファイルの内容 ───→  Claude
     │      ←─── tool_use (何をするか) ──────
     └→ ローカルで実行 → 結果を返す → 繰り返し
```
